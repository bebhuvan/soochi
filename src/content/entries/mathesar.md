Mathesar puts a familiar spreadsheet-style interface over PostgreSQL. People
without SQL can create and edit records, relate tables, filter and group data,
build visual queries and collaborate, while administrators retain PostgreSQL's
native schemas, roles and permissions.

It can connect to an existing database or start a new one, is self-hosted and
does not trap the data behind a proprietary format. Mathesar Foundation, a
nonprofit, maintains the GPL-licensed project. The software is in public beta,
so teams should test backup, permissions and upgrade procedures before placing
important programme data in production.
