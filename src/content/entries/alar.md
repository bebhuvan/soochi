Alar (ಅಲರ್, meaning "to blossom") is a comprehensive open-source Kannada-English dictionary built on the work of lexicographer V. Krishna. With 247,674 English entries and 156,672 Kannada entries, it is the most extensive freely accessible bilingual dictionary for Kannada. The project was built by Zerodha's technology team and released as open data under the Open Database Licence (ODbL), with the full dataset available on GitHub. The web interface provides fast full-text search in both directions. For researchers, Alar is a foundational language resource — alongside Sanchaya's literary tools and Indic Digital Archive Foundation's Olam (Malayalam dictionary), it represents the growing ecosystem of open-source Indian language infrastructure built by the tech community.
