AnyDoc is Firecrawl's open-source document parsing library, purpose-built to handle the messy, multi-format reality of real-world documents. It converts Word (.docx), PowerPoint (.pptx), Excel (.xlsx), OpenDocument (.odt/.ods/.odp), RTF, EPUB, CSV, and PDF files into clean, structured Markdown — preserving headings, lists, tables, and text formatting. Built in Rust for speed and reliability, with first-class Node.js and Python bindings. For Indian researchers and civic technologists, AnyDoc complements Tabula and LiteParse by covering the formats those tools don't: government data often arrives as .xlsx, .docx, or .pptx files, and AnyDoc turns all of them into the same clean text format for downstream processing. MIT-licensed, 8K+ GitHub stars, from the Firecrawl team.
