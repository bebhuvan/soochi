Taguette supports qualitative analysis of interviews, reports, field notes and
other text. Researchers import documents, highlight passages, organise them
with a coding scheme and export their codes, highlights and project data for
further analysis or reporting.

The desktop mode keeps a project on the researcher's own computer. Teams can
use the hosted service or install Taguette on their own server for
collaboration. It accepts common formats including PDF, DOCX, ODT, RTF, EPUB,
HTML and plain text, but it is designed for textual rather than audio or video
analysis.
