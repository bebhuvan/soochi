Quarto combines narrative text, citations, code and computational output in a
single source document. It works with Jupyter and languages including Python,
R, Julia and Observable, and can render the same project to HTML, PDF, Word,
ePub, presentations and other formats.

For research and policy teams, this makes analysis and publication easier to
keep in sync: tables and charts can be regenerated when data or code changes.
Quarto can also produce complete websites, books and dashboards. It is
developed by Posit, while the current command-line tool is free and
MIT-licensed.
