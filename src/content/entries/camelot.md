Camelot is an open-source Python library that extracts tabular data from text-based PDF documents into structured formats including Pandas DataFrames, CSV, JSON, and Excel. It provides two extraction parsing methods: Lattice (for tables with demarcated grid lines) and Stream (for tables delineated by whitespace).

For researchers, data journalists, and civic technologists analyzing government budget reports, parliamentary responses, and statistical publications where data is trapped in PDF tables, Camelot offers a scriptable, reproducible pipeline with visual debugging plots for table boundary verification.
