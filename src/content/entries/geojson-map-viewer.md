GeoJSON Map Viewer is a client-side cartography tool built by Simon Willison that allows users to quickly inspect, style, and composite geographic vector data over OpenStreetMap tiles.

The tool operates entirely within the browser with no backend server. Users can paste GeoJSON, load files from CORS URLs or GitHub Gists, customize colors and opacities across multiple layered shapes, save workspace state in URL hash fragments, and export high-resolution PNG maps.
