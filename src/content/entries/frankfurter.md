Frankfurter is a free, open-source currency data and foreign exchange API that publishes daily exchange rate time series from 84 central banks and monetary authorities without API keys or usage quotas.

Covering 201 fiat currencies with historical depth back to 1948, the platform provides blended reference rates, provider-specific filtering (e.g., ECB or Reserve Bank of India), NDJSON/CSV streaming, and native Model Context Protocol (MCP) integrations for agentic workflows.
