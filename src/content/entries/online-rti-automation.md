Online RTI Automation is an open-source civic technology workflow designed to automate Right to Information (RTI) filings on both the Central government portal (rtionline.gov.in) and the Karnataka state portal (rtionline.karnataka.gov.in).

The framework uses Claude Code CLI paired with Playwright CLI to execute reusable instruction templates (`rti_submit_request_template.md` and `karnataka_rti_submit_request_template.md`). It automates complex form navigation and department selection using curated reference databases of public authorities, while preserving human-in-the-loop security for OTP verification and fee payments.
