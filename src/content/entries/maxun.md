Maxun lets a researcher record browser actions or describe an extraction task,
then rerun it to collect structured information from websites. It supports
pagination, scheduled runs, authenticated pages, crawling, screenshots and
exports to spreadsheets or APIs, without requiring the user to write a custom
scraper.

The AGPL-licensed application can be self-hosted, while a hosted version is
also available. Web extraction must still respect applicable law, privacy,
copyright, site terms and robots guidance. Automated workflows also need
monitoring because changes to a source website can silently alter or break the
result.
