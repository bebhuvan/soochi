Datasette turns structured data into an interactive website and JSON API. It
can publish SQLite databases directly, while companion tools and plugins help
import CSV, JSON and data from other databases, add full-text search, create
visualisations and control access.

It is especially useful for journalists, researchers, archives and public
agencies that need to make a dataset browsable without building a custom web
application. Datasette runs locally or on a server; publishing a public
instance still requires suitable hosting and attention to privacy and access
controls.
