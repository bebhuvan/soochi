Uwazi is a flexible documentation database developed by HURIDOCS for human
rights organisations. Teams can define record templates, upload evidence,
connect people, events and documents, search across collections, map records
and publish selected material through multilingual public pages.

Granular users, groups and permissions allow one installation to support
private documentation alongside public collections. The software can be
self-hosted without a licence fee; HURIDOCS also offers paid managed hosting,
implementation and information-management support.
