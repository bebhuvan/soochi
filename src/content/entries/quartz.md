Quartz is an open-source static site generator purpose-built for digital gardens — interlinked collections of notes, ideas, and knowledge that grow over time. Unlike traditional blogging platforms that emphasise chronological posts, Quartz treats your Markdown files as a network of linked thoughts, with features like backlinks, graph view, full-text search, and local graph visualisation. For researchers, civic organisations, and community groups, Quartz is the ideal tool for publishing documentation wikis, research notes, project handbooks, or collective knowledge bases that evolve with the work. It requires no database, generates static HTML (fast, secure, cheap to host), and can be deployed to GitHub Pages or any static host. 12K+ GitHub stars, MIT-licensed, actively maintained.
