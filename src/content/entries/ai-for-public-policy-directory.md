The directory collects policy-facing AI tools and civic applications that are
otherwise scattered across personal repositories and institutional websites.
Its listings include parliamentary trackers, budget visualisations, regulation
monitors, analytical tools and citizen-facing projects, with search and topic
filters running entirely in the browser.

The catalogue is maintained as community-editable YAML and automatically
checks new submissions for missing fields, bad links and duplicates. The
repository describes itself as open source but does not currently provide a
recognised licence file, so Soochi records the licensing status as unclear.
