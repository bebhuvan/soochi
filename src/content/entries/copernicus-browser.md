Copernicus Browser is the visual gateway to the full Sentinel satellite constellation: Sentinel-1 (radar), Sentinel-2 (optical, 10 m), Sentinel-3 (ocean/land), Sentinel-5P (atmospheric chemistry), and Sentinel-6 (sea level). Unlike Google Earth Engine, it requires no coding — you can visualise, composite, and download scenes in the browser. The underlying Copernicus Data Space Ecosystem provides API access and cloud processing. All data is free and open for any use.
