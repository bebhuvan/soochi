Avni is an open-source platform built specifically for Indian nonprofits running community programmes. It combines a mobile app for field workers (offline-first, works on low-end Android phones), a web app for programme managers to design workflows and view dashboards, and a backend that handles data synchronisation. Unlike generic data collection tools, Avni is designed for longitudinal tracking — following the same beneficiary over time through health visits, educational interventions, or livelihood support. It supports multiple languages including Hindi, Marathi, Kannada, and other Indian languages. Used by organisations across health (TB, maternal health), education, sanitation, and agriculture sectors. The project is stewarded by Samanvay Foundation.
