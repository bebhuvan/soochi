Kepler.gl, created by Uber and now open-source, is a browser-based tool for visualising large geospatial datasets. Drop a CSV or GeoJSON file with location data, and immediately create heatmaps, cluster maps, time-animated flows, 3D hexbin layers, and network maps. For Indian researchers, Kepler.gl is the fastest way to visualise patterns in spatial data — plot all MGNREGA worksites, animate the spread of a disease outbreak, map urban growth from satellite data, or show migration flows between districts. It handles millions of points smoothly using WebGL rendering. The tool runs entirely in the browser (no server needed), and maps can be exported as images or interactive HTML. Particularly useful for exploratory analysis before committing to a full GIS workflow.
