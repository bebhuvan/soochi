ezesri is an open-source geospatial data extraction tool and searchable directory created by data journalist Matt Stiles to extract layers from municipal and institutional ArcGIS REST API endpoints.

Available as a zero-install browser app, Python SDK, and CLI, it handles Esri record pagination automatically, supports spatial bounding-box and SQL filtering, and exports features into GeoParquet, GeoJSON, GeoPackage, and Shapefiles. The accompanying directory indexes over 24,000 public government feature services worldwide.
