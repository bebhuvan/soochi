Apache Superset is a modern, enterprise-ready open-source business intelligence and data exploration web application. It connects to virtually any SQL-speaking database or data warehouse (PostgreSQL, MySQL, ClickHouse, BigQuery, DuckDB, Trino) and provides a no-code visual chart builder alongside a rich SQL IDE.

For civic data initiatives, research institutes, and public policy think tanks, Superset provides a scalable platform to build interactive public data dashboards, embed interactive visualisations in websites, and manage granular role-based access controls over sensitive research datasets.
