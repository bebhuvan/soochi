OpenEcon.ai is an open-source initiative founded by economist Lu Han that equips modern AI assistants (such as Claude Code and Codex) with specialized tools for economics research and econometrics.

The project encompasses:
- **Economic Data Search** (`data.openecon.ai`): A natural-language interface and Model Context Protocol (MCP) server indexing over 330,000 economic indicators across global databases (including the World Bank and FRED).
- **Stata MCP Server & MATLAB Integration**: Tools that allow LLM agents to safely execute statistical code, generate figures, and export publication-ready regression tables.
- **Workflow Skills**: Standardized agent skills for automated referee report generation, Beamer presentation slide drafting, literature synthesis, and Overleaf synchronization.
